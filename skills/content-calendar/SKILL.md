# Content calendar

**Drafts only. Never post, send, or publish. The user approves anything external.** Output is one local markdown file; no webhooks, no platform APIs.

## Steps
1. Ask the brand or business, the period (week or month), and which channels the user actually uses. If they have a brand voice file, ask for its path, read it and follow it.
2. Plan a dated list: date, channel, topic, one-line angle, draft copy, and what it needs from the user (photo, fact, approval).
3. Use only claims the user has supplied or allowed. No review quotes, stats or prices unless given. Mark open facts as "needs input".
4. Write ./content-calendar-<brand>-<period>.md. Keep drafts short and plain.
5. End with a list of items needing the user's approval before anything goes out. Do not schedule or post anything.
